# Todos App - CRUD To Do List
Fahri Qeizal Sabil - 41155050240020

# Deskripsi
Aplikasi Todos App merupakan proyek sampel CRUD (Create, Read, Update, Delete) berbasis React Native dan Expo yang terintegrasi dengan basis data cloud Firebase Firestore. Aplikasi ini tersusun atas beberapa komponen utama, yaitu Config.js untuk inisialisasi koneksi Firebase, App.js sebagai pengatur navigasi layar menggunakan Stack Navigator, Home.js untuk menampilkan daftar tugas secara real-time serta menambah dan menghapus data, serta Detail.js yang khusus menangani proses pembaruan (update) tugas. Selain itu, versi basis data Firebase pada proyek ini telah disesuaikan dari versi 9 ke versi 8 agar dapat dieksekusi secara langsung melalui platform Expo Snack.
